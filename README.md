# STAT 330: Regression Coursework

R Markdown work from STAT 330 (regression analysis) at BYU. Each file fits a regression model to a small dataset and checks whether the model holds up.

| File | Topic | Data |
|---|---|---|
| [Homework 1.Rmd](Homework%201.Rmd) | Simple linear regression | Wind speed at two sites (`Windmill.txt`) |
| [Homework 2.Rmd](Homework%202.Rmd) | Checking model assumptions | Car speed vs. stopping distance (`StoppingDistance.txt`) |
| [Homework 3.Rmd](Homework%203.Rmd) | Inference: confidence intervals and tests | Snowfall vs. stream runoff (`water.txt`) |
| [Module 2 - In-Class Coding Analysis.Rmd](Module%202%20-%20In-Class%20Coding%20Analysis.Rmd) | In-class: checking model assumptions | Car weight vs. MPG (`MPGData.txt`) |
| [Module 3 - In-Class Coding Analysis.Rmd](Module%203%20-%20In-Class%20Coding%20Analysis.Rmd) | In-class: inference | Car weight vs. MPG (`MPGData.txt`) |
| [GroupProject1.Rmd](GroupProject1.Rmd) | Group project | Premier League 2018-19 player goals vs. appearances (`premier1819.csv`) |

`Homework-1.html` and `Homework-2.html` are the finished reports. Download one and open it in a browser to read it without R.

## Run it

Open `STAT330.Rproj` in RStudio, open any `.Rmd` file, and click **Knit**.

**Tools:** R, R Markdown, ggplot2
